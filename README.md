## Projects

**[deep-learning-projects](https://github.com/martinheger/deep-learning-projects)**
CNN image classifier with a [live demo](https://huggingface.co/spaces/MartinH-01/Flowers), a GPT-style transformer trained on Czech laws, and fine-tuning Gemma 3 for structured output. Also includes a write-up of an individual case study: fine-tuned Czech transformers vs. classical ML on news classification (104k articles, 24 classes, macro F1 up to 0.95).

**[real-estate-price-prediction](https://github.com/martinheger/real-estate-price-prediction)**
Prague apartment price prediction with a stacking ensemble of XGBoost, LightGBM and CatBoost (9.47 % MAPE). Optuna tuning, out-of-fold blending, and a validation design with 10 repeated hold-out runs that separates tuning from performance estimation.

**[stochastic-analysis-quant-models](https://github.com/martinheger/stochastic-analysis-quant-models)**
Stock price simulation with geometric Brownian motion, time series analysis in Python and R, and numerical optimization methods.

**[sql-r-powerbi-nba-analytics](https://github.com/martinheger/sql-r-powerbi-nba-analytics)**
End-to-end data pipeline on NBA data: a custom relational model in MS SQL Server, analysis in R, and a Power BI dashboard.
